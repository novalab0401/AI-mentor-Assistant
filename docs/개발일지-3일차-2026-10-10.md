## 4. 평가 기준 변경 (전공·진로 소개 · 모의 시연)

**양식 A — 특화 4개 채택 (김재호 검토)**: 학생 파악과 맞춤, 진로 연결과 실천 안내, 균형과 현실성, 학생 질문 응답.
→ 평가지 = 공통 5개(구조·설명·질문의 질·비언어·시간) + 전공 소개 6개(정확성·PPT·위 4개).
"학생 파악", "학생 질문 응답"은 학생 역할이 없는 혼자 연습이면 판단 불가 허용.

**양식 B — 앵커(판단 기준 예시) 1차** (김재호 경험: 신입 멘토가 가장 많이 하는 실수)

| 항목 | 앵커 |
|---|---|
| 시간 관리 | 계획보다 3분 넘게 초과하면 2점 이하, 초과 + 진로·정리 못 하면 1점 |
| 수업 구조 | 학과·진로가 중심. 다른 주제(입시 경험·학교생활)가 중심이면 2점 이하 |
| 설명의 적절성 | 대학 과목 용어를 대상 수준에 맞게 풀지 않고 나열하면 1~2점. 4점: 일상 예시로 풀고 이해 확인 |
| 학생 질문 응답 | 질문 없다고 그냥 끝내면 1점. 4점: 학생이 궁금해할 예상 질문을 직접 꺼내 답함 |
| 진로 연결과 실천 안내 | "입학처 확인"·"찾아보세요"는 2점. 3점: 과목·활동을 이름까지 구체적으로. 4점: 학생 관심에 맞춘 행동 + 스스로 판단할 기준 |

- 앵커는 공통 루브릭 문장을 바꾸지 않고 평가지별로 보탬(2층 구조 유지).
- 선배 평가 화면에 "판단 기준 예시 보기", AI에는 "기준 문장보다 우선"으로 전달.
- 채점 지시문 버전: v1 → v6 (결과마다 버전 기록 → 버전 간 비교 가능).

## 5. 확인된 것 (보고서용 근거)

- 예측 대비 AI 점수 일치: 특화 4개 첫 채점 4개 중 3개 일치, 앵커 반영 후 예측 4개 모두 일치.
- 같은 전사문 반복 채점: 대상만 바꾼 두 번의 채점에서 11개 항목 점수 동일 → 흔들림이 크지 않다는 첫 신호. 단, 경계에 걸친 발화는 흔들림 발견 → **앵커가 흔들림을 줄이는 수단**임을 확인.
- AI는 근거가 없으면 점수를 주지 않음(비언어·PPT·잘린 전사문의 시간).

## 6. 설계 판단

- **기준 문장 + 앵커 2층**: 추상적인 문장만으로는 사람도 AI도 경계에서 갈림. 실제 발화 예시가 경계를 고정.
- **사실 정보는 사람이 입력**(수업 시간·대상): AI가 추측할 수 없는 것은 칸으로 받는다. 추측해야 하는 상황에서는 판단 불가로 둔다.
- **한 실수는 한 항목에서**: 중복 감점은 멘토에게 같은 지적을 반복하고 점수를 왜곡함.
